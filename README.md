## 🛠️ 安装步骤

**整站包（16 套）**

1. 上传源码到网站根目录；
2. 导入数据库文件（`.sql`）；
3. 修改 `application/database.php` 里的数据库配置；
4. 访问 `域名/install.php` 按提示完成安装；
5. 后台地址：`域名/admin.php`。

**模板包（47 套）**

1. 解压后把模板文件夹上传到苹果CMS的 `template/` 目录；
2. 后台 → 站点设置 → 模板选择 → 选中对应模板目录；
3. 部分模板需改 `template/` 下的配置文件填写站点信息。

**播放器插件（4 套）**

1. 上传播放器文件到网站根目录的 `/player/` 目录；
2. 修改播放器配置（`config.php` 或数据库连接）；
3. 后台 → 视频 → 播放器 → 添加播放器；
4. 填写播放器接口地址（如 `http://域名/player/index.php?url=`）；
5. 超级播放器需额外运行 `install.php` 安装。

**影视 APP（4 套）**

1. 修改 API 接口地址，指向你的苹果CMS后台；
2. 用对应工具编译（Android Studio / HBuilderX / Xcode）；
3. 安装测试，确认接口对接正常；
4. 按需修改 UI 和功能。

## ❓ 常见问题

- **整站源码和模板主题有什么区别？** 整站包是「程序 + 数据库 + 模板」的完整系统，装上就能用；模板包只有前端模板，要装在已有的苹果CMS上。
- **装完前台 404 / 分类页打不开？** 没配伪静态。按服务器环境加对应规则，宝塔面板里可以直接选苹果CMS的伪静态模板。
- **模板上传了后台却选不到？** 检查目录名和权限，模板文件夹要直接放在 `template/` 下，不要多套一层。
- **播放器添加后播不了？** 接口地址填错，或播放器没配好 JSON 接口。超级播放器记得先跑 `install.php`。
- **采集不到资源？** 采集接口和资源站要自己配，包内不含资源站账号。
- **PHP 版本怎么选？** 别用 PHP 8，苹果CMS V10 在 7.0~7.4 最稳。
